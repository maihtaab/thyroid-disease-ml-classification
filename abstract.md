# Project Abstract

This project investigates the use of machine learning models to predict hyperthyroid disease using the Thyroid Disease Database. The problem being addressed is whether patient medical attributes can be used to accurately classify the presence of a hyperthyroid condition.

The main objective of the project is to compare multiple supervised learning methods and identify the model that provides the best predictive performance on this classification task. In addition to model comparison, the project will examine the effects of preprocessing decisions such as handling missing values, encoding categorical variables, scaling features, and addressing potential class imbalance.

The methodology will include exploratory data analysis, data cleaning, train-test splitting, model training, and evaluation using multiple performance metrics. The models planned for this project are Logistic Regression, Decision Tree, and Random Forest, with hyperparameter tuning used to improve performance and reduce overfitting.

The dataset used is the Thyroid Disease Database from the UCI Machine Learning Repository, which contains medical and diagnostic attributes related to thyroid conditions. The expected outcome is to determine which model performs best and to better understand which features are most useful for thyroid disease prediction.
